Adding an icon to images/sprites.svg

  1. Add a <symbol id="icon-id" viewBox="0 0 16 16"></symbol> element to images/sprites.svg.
  2. Within the <symbol></symbol> tags, add the <path></path> and equivalent elements for drawing the SVG.
  3. Add the icon to this page's list above.

Using an icon in HTML

The following code will display a Bootstrap Icon for use inline with text: 

<svg class="bi align-middle me-1" width="16" height="16"
     fill="currentColor" aria-hidden="true">
  <use xlink:href="images/sprites.svg#box-arrow-up-right"/>
</svg>

Notes:

  1. Use currentColor for strokes and fills so the icon inherits the surrounding text colour.
  2. Mark decorative icons with aria-hidden="true" on the <svg> element.
  3. Include the class bi for Bootstrap Icons.
  4. Include the class me-1 for a small margin to the right when used with inline text.
