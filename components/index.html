Modal

Reference: /docs/5.3/components/modal/

Basic modal

The basic modal shows a dialog with a header, body and footer. It can be closed with the X button, the Close button, pressing Escape, or clicking outside the dialog.

Static backdrop

The backdrop is static: clicking outside the dialog does not close it, and Escape is disabled. It can only be closed with the Close button. The dialog is also vertically centered with the modal-dialog-centered class.

Navs & Tabs

Reference: /docs/5.3/components/navs-tabs/

Clicking an inactive tab switches the visible pane.

Offcanvas

Reference: /docs/5.3/components/offcanvas/

Basic offcanvas

The default offcanvas slides in from the left using the offcanvas-start class. A backdrop covers the page, and clicking it closes the panel.

Body scrolling

This panel slides in from the right with offcanvas-end. With data-bs-scroll the page body scrolls behind the panel, and there is no backdrop.

Body scrolling and backdrop

This panel slides in from the top with offcanvas-top. The page body scrolls behind it, and the backdrop is shown.

Static backdrop

This panel slides in from the bottom with offcanvas-bottom. The backdrop is static: clicking it does not close the panel; only the Close button does.
